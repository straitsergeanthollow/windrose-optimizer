## What this is NOT
This is **not** another Python script that requires virtual environments, dependency hell, or compiling from source. It is **not** a web-based SaaS with recurring fees. It is **not** a "generate once and forget" tool — it's a live interactive trainer.

## What it actually does
**Windrose Trainer 2026** is a standalone Windows executable that reads wind direction and speed data from CSV files and trains you to rapidly interpret windrose (compass rose) patterns. It simulates real-time weather data visualizations, quizzes your orientation skills, and logs accuracy over time — all in a single `.exe` file.

## ❓ FAQ

> [!TIP]
> Quick answers to the most common questions.

**Q: Does this tool modify my system files or registry?**  
A: No. It's portable — writes only to its own folder and `%USERPROFILE%\AppData\Local\WindroseTrainer` for logs.

**Q: Can I use this for real-time weather monitoring?**  
A: No. It's a **training tool** that replays static or pre-recorded wind data. For live data, look at physical anemometers or dedicated APIs.

**Q: How do I get new sample datasets?**  
A: Extra datasets are available in the `samples/` folder of this repo. Just drag the `.csv` onto the window.

**Q: The .exe is flagged by antivirus — false positive?**  
A: Likely yes. This executable is packed with UPX to reduce size, which can trigger signature-free detections. Check VirusTotal (link in Community section) or compile from source yourself (if you contribute to our open dataset).
